# 静心寺 · 素材与许可说明

本原型全部可商用，未使用受版权保护的录音或付费模型。

## 代码与 3D
- 游戏代码为静心寺项目原创。
- 全部 3D 造型（小和尚、如来佛祖、四大天王、韦陀、殿宇、香炉、木鱼、蒲团等）均由 Three.js 几何体现场搭建，未使用第三方模型（未采用 Quaternius / Kenney 等，以免引入额外授权流程）。

## 音频（全部为实时合成，原创）
浏览器 WebAudio 在运行时合成，无任何第三方录音、采样或商业唱片：
- **寺院背景音乐**：多层低频持续音（drone）、歌唱碗/磬的非谐和分音、稀疏的古琴拨弦与笛类音色（五声音阶短句）。
- **打坐诵经回路**：带共振峰的人声式持续音 + 轻柔磬音；打坐时背景音乐自动压低（duck），起身后再升起。
- **木鱼、佛珠**：程序生成的短促敲击。

以上音频均为原创，可作商业使用。

## 字体
登录页与界面可选加载 [Noto Serif SC](https://fonts.google.com/noto/specimen/Noto+Serif+SC)（SIL Open Font License 1.1，Google Fonts）。系统会回退到宋体等本地衬线字体。

## 角色设定
所有可操作与在线角色均为小和尚，仅袈裟颜色与细节饰物（念珠、挂袋、头巾、袈裟贴块等）不同，没有其他角色类型。
